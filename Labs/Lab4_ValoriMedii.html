Medii temporale și statistice

Laboratorul 4, DEPI

1 Obiectiv

Folosiți mean(), std() și var() pentru a caracteriza măsurători reale. Distingeți mediile calculate în timp de cele calculate pe un ansamblu de observații, alegeți dimensiunea corectă a matricei și explicați de ce media unor rapoarte diferă de raportul sumelor.

2 Aspecte teoretice

2.1 Media, varianța și devianța standard statistică

Mediile statistice sunt definite pe baza distribuției de probabilitate, nu pe baza unei anumite secvențe de măsurători.

Pentru o variabilă aleatoare continuă A, cu densitatea de probabilitate w_A(x), media statistică este

\mu_A=\mathrm{E}\{A\}=\int_{-\infty}^{\infty}x\,w_A(x)\,dx.

Varianța statistică este:

\sigma_A^2=\mathrm{E}\{(A-\mu_A)^2\} =\int_{-\infty}^{\infty}(x-\mu_A)^2w_A(x)\,dx.

Devianța standard este rădăcina pătrată a varianței:

\sigma_A=\sqrt{\sigma_A^2}.

Pentru o variabilă aleatoare discretă, integralele se înlocuiesc cu sume.

Observație: Când lucrăm cu date, nu putem calcula direct aceste integrale, deoarece ele presupun cunoașterea distribuției de probabilitate. În practică, folosind vectori lungi de date măsurate, calculăm medii temporale. Dacă este îndeplinită proprietatea numită ergodicitate, mediile temporale converg către mediile statistice când numărul de eșantioane tinde la infinit.

2.2 Media, varianța și devianța standard temporală

Mediile temporale sunt cele pe care le calculăm în practică, de exemplu în Matlab, când avem un vector finit de eșantioane.

Pentru un vector finit x[1],\ldots,x[N], media temporală este

m = \bar{X} =\frac{1}{N}\sum_{n=1}^{N}x[n].

Varianța temporală este:

v = \frac{1}{N-1}\sum_{n=1}^{N}(x[n]-\bar{X})^2

sau:

v = \frac{1}{N}\sum_{n=1}^{N}(x[n]-\bar{X})^2

Diferența constă în primul termen, numit factor de normalizare, care este \frac{1}{N-1} sau \frac{1}{N}. Alegerea depinde de faptul că media \bar{X} este estimată din aceleași date sau este cunoscută a priori:

  • folosiți \frac{1}{N-1} când media \bar{X} este estimată din aceleași date;

  • folosiți \frac{1}{N} când media \bar{X} este media adevărată, cunoscută a priori.

Devianța standard temporală este rădăcina pătrată a varianței:

s = \sqrt{v}.

Pentru o secvență de lungime infinită, mediile temporale sunt definite ca limite ale mediilor calculate pe intervale din ce în ce mai lungi.

2.3 Calculul mediilor în Matlab

Pentru un vector, mean() calculează media aritmetică. Implicit, var() și std() folosesc normalizarea cu N-1, iar var(x,1) și std(x,1) folosesc N:

x = [1, 2, 1, 5, 6, 5, 6, 6, 7, 10, 14, -3];
m = mean(x)
v = var(x)       % numitor N-1
s = std(x)       % rădăcina pătrată a lui var(x)
vN = var(x, 1)   % numitor N
sN = std(x, 1)   % rădăcina pătrată a lui var(x, 1)

Pentru o matrice X, funcțiile mean(X), std(X) și var(X) operează implicit de-a lungul coloanelor, obținând un rezultat pentru fiecare coloană.

Pentru a calcula mediile de-a lungul liniilor, specificați argumentul de dimensiune dim=2 (consultați documentația). De exemplu, pentru o matrice X de dimensiune N × M, următoarele comenzi calculează medii temporale și medii pe ansamblu:

% mean(X, dim)
mean(X)     % Operează pe coloane. Produce un vector 1 × M de medii pe coloane
mean(X, 2)  % Operează pe linii. Produce un vector N × 1 de medii pe linii
% La fel pentru var()
% Apel: var(X, normalizare, dim)
var(X)         % Folosește 1/(N-1), operează pe coloane
var(X, 1)      % Folosește 1/N, operează pe coloane
var(X, 0, 2)   % Folosește 1/(N-1), operează pe linii
var(X, 1, 2)   % Folosește 1/N, operează pe linii
% La fel pentru std()
std(X)         % Folosește 1/(N-1), operează pe coloane
std(X, 1)      % Folosește 1/N, operează pe coloane
std(X, 0, 2)   % Folosește 1/(N-1), operează pe linii
std(X, 1, 2)   % Folosește 1/N, operează pe linii

2.4 Încărcarea variabilelor dintr-un fișier

load() citește variabile salvate într-un fișier .mat, salvat în prealabil cu save():

D = load('data.mat');   % Stochează variabilele salvate într-o structură
x = D.x;               % Accesează variabila cu numele x

load('data.mat');       % Încarcă variabilele direct în Workspace

Cu un argument de ieșire, variabilele devin câmpuri ale unei structuri, accesibile folosind punctul. Fără un argument de ieșire, ele apar direct în Workspace și pot suprascrie variabile cu aceleași nume. Fișierul trebuie să fie în directorul curent sau să fie indicat prin calea sa.
